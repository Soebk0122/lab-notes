# 学生成绩管理系统

本程序由我 + DeepSeek 协作完成。

## 功能

- 1. 录入成绩：输入姓名和分数，存进 ArrayList<Student>
- 2. 显示全部：按当前顺序列出所有学生
- 3. 按分数排序：使用 Collections.sort，从高到低
- 4. 退出

## 运行

javac -encoding UTF-8 Student.java Main.java
java Main

## 已处理的边界情况

- 菜单输入非数字：提示「请输入数字！」并重新显示菜单
- 分数输入非数字：提示后取消本次录入，程序不崩
- 分数不在 0~100：提示后取消本次录入
- 一个学生都没有时查看/排序：提示「还没有学生，请先录入」
